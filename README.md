# Cat Prank — برنامه شوخی با گربه 🐱📱

یک برنامه اندرویدی شوخی و سرگرمی مدرن، جذاب و خنده‌دار که با **Jetpack Compose** و **Material 3** توسعه داده شده است.

---

## 🌟 ویژگی‌های برنامه (Features)

1. **تله لمسی گربه (Cat Trap)**:
   - صفحه تمام‌صفحه که در ظاهر فقط تصویر یک گربه آرام و بامزه است.
   - به محض لمس گربه یا صفحه توسط دوستان، صدای جیغ و میومیو بلند، انیمیشن شوکه شدن گربه و لرزش گوشی فعال می‌شود!
   - دارای دکمه خروج مخفی در بالای صفحه ویژه صاحب گوشی.

2. **جعبه صداهای شوخی (Soundboard)**:
   - شامل ۸ افکت صوتی صوتی واقعی و کمدی:
     - میو بلند و کش‌دار
     - جیغ خنده‌دار و وحشت‌زده
     - فیشش و عصبانیت گربه (Hiss)
     - بچه گربه ملوس
     - تعجب گربه (Huh?!)
     - خرخر عمیق و لرزان
     - آواز اپرای گربه
     - ترپ ترپ و بازیگوشی

3. **حالت میومیو مداوم (Continuous Loop)**:
   - پخش رگباری میومیو در فواصل زمانی با شمارنده تعداد میومیوها و امکان توقف در هر لحظه.

4. **بمب غافلگیری با تایمر (Prank Bomb Timer)**:
   - تایمر ۵، ۱۰ یا ۲۰ ثانیه‌ای برای قرار دادن گوشی روی میز یا کنار دوستان؛ به محض پایان زمان، صدای گوشی حداکثر شده و جیغ گربه به صدا درمی‌آید.

5. **طراحی مدرن و سازگار با تبلت و موبایل**:
   - توسعه داده شده بر پایه استاندارد Material 3
   - پشتیبانی از حالت عمودی و افقی (Adaptive UI)
   - مدیریت هوشمند ولوم صدا، خروج کنترل‌شده و بازخورد لمسی (Haptic Feedback)

---

## 🛠️ تکنولوژی‌ها و معماری (Tech Stack)

- **زبان**: Kotlin
- **رابط کاربری**: Jetpack Compose با Material 3
- **معماری**: MVVM (Model-View-ViewModel) + StateFlow
- **مدیریت صوت**: Android MediaPlayer و AudioManager
- **تست‌ها**: Robolectric و Unit Tests
- **تارگت SDK**: Android 14+ (API 34)

---

## 🚀 نحوه اجرا در اندروید استودیو (How to Run)

1. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/muhammad483882-gif/CatPrank.git
   ```
2. پروژه را در **Android Studio** باز کنید.
3. اجازه دهید Gradle فرآیند Sync را انجام دهد.
4. پروژه را روی یک گوشی یا شبیه‌ساز (Emulator) با زدن دکمه Run اجرا کنید.
